# Project design tokens & theme / uniform policy

Single source of truth for every Python file in this workspace. Any change to a
color, font, text rule, or mix parameter happens in this file, and the consumers
read from it — never duplicate values across modules.

## Design tokens (shared)
- Brand: deep slate (`#0d1017`) background, panel (`#161b26`),
  accent sky (`#38bdf8`), win gold (`#facd15`), muted text (`#94a3b8`).
- Font stack (PIL), resolved in order `$ASSETS_FONT_DIR/fonts/` -> `./fonts/`
  -> `C:/Windows/Fonts` -> `/usr/share/fonts/truetype/dejavu` -> bitmap:
  headlines `arialbd.ttf`; win centerpiece `impact.ttf`; subtitles `calibri.ttf`;
  kicker eyebrows `calibrib.ttf`; stat numbers `consolab.ttf`.
- Sizes: title 54, win title 64, subtitle 26, kicker 17, stat 64.
- Frame: 800x450, 750 ms per frame.
- Text: greedy word wrap (`_wrap_text`) so lines never overflow; drop shadow
  under headlines; accent underline bar below the headline.

## Brag scene plan (generate_video.py)
Scenes run in this order; the win centerpiece is the emotional peak:

| # | kicker | kind | frames |
|---|---|---|---|
| 1 | logo reveal | title | 3 |
| 2 | **critical hit** | **win (gold, Impact, hot glow)** | 4 |
| 3 | log line | description | 3 |
| 4+ | feature N | one frame per feature | 1 each |
| - | built with | stack | 2 |
| - | community | proof (stats · features · deps) | 2 |
| - | join us | CTA "Star it. Fork it. Ship it." | 2 |

- Win centerpiece only: gold headline + gold glow + hot sparkles.
- Every frame: kicker eyebrow, accent underline, progress bar bottom.
- Background: gradient + drifting glow + diagonal light streaks + breathing
  vignette; cycle over the frame timeline (`t` = frame / total).

## Music mixing parameters (shared)
- Music sits `18 dB` below the narration (configurable, default 18).
- Music-only path: `-16 LUFS` when no narration is detected.
- Final mix target: `-14 LUFS integrated, -1 dBTP` (EBU R128).
- Fades: 2s in, 3s out; sidechain compress `threshold=0.02 ratio=8 attack=40 release=700`.
- ffmpeg >= 4.4 required (uses `amix normalize=0`, two-pass `loudnorm`).

## Theme / uniform rules
- One heavy H1 only. Equal-or-smaller H2/H3 for every section — never H4+.
- No headings or body text inside a form. Debug info goes in a `pre.sh` block.
- Keyboard shortcuts are **not** used as a user affordance (no `Ctrl+K` style).
- Project files live under `OneDrive/Documents/IOTA/plant-disease-system/`;
  the video generator companion scripts `generate_video.py` and `add_music.py`
  live in this working copy and must stay in sync with the tokens above.
